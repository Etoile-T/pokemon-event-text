# 書いた あとの 見直し

順番: ⓪ 公式の 型と くらべる → ① humanizer（casual）で AI っぽさを ぬく → ② 4つの 視点で 読みくらべる → ③ 道具で 検査 → ④ 直して もう一度 ③。
ユーザーに 見せる ときは「手本に した 公式の 台詞（ラベル名と 型だけ）→ 下書き → まだ 気に なる 所 → 直した もの → 検査の 結果」の 順。

## ⓪ 公式の 型と くらべる（いちばん さきに）

書く まえに 読んだ 公式の 台詞（`scripts/find_official.py --speaker … --kind …`）と、下書きを ならべて 見る。

| 見る 所 | 公式の 目安（くわしくは format.md と characters/*.toml の [official]） |
|---|---|
| 一人称・相手の 呼び方 | [official] と 同じか。ちがうなら [project] か [conflicts] に 理由が あるか |
| 語尾 | [official] の 語尾が 1つは 入って いるか。公式に ない 語尾（例「〜なさいよね」）を くりかえして いないか |
| 1行の 長さ | 17字まで（18字を こえたら 書きなおす） |
| 1ページ | 2行が ふつう。3行目は \l で 足して よい |
| 記号 | 「…」は 1つが ふつう。さけびの 小さい つ は「ッ」（あッ！）。「、」「。」は 使わない |
| 地の文 | 人から → もらった！、わたす 人が いない → てにいれた！（つめて 書く） |
| 場面の 長さ | 町の 人・トレーナーは 1〜2ページ。名前の ある 人の 大事な 場面だけ 長く |

- 公式の 文を 写して いないか（公開 リポジトリに 入る）。型を あわせ、言葉は 自分で 書く
- 見せる ときは「どの 公式の 台詞の 型に あわせたか」を ラベル名で 言う（例: 「CeruleanCity_Text_RivalIntro の あいさつ → 本題の 型」）

## ① humanizer の casual の 決まり（要点）

harupan119/claude-skills-ja の humanizer-ja-modes（MIT）の 考え方を、ゲームの 台詞むけに まとめた もの。原文は 写して いない。

検出は 3つの 層で 見る:

1. **記号の 層**: ダッシュ（― — –）、コロン、（ ）、絵文字。台本では charmap に ない ので 道具が エラーに する。「！」を 連ねすぎない。「…」は 間の ときだけ
2. **言葉の 層**: 決まり文句（かけがえのない・きずなの ちから・たいせつなのは）、つなぎの 連打（それに・さらに・だから が 続く）、説明の 型（つまり・と いう ことは）、語尾の 単調さ（全員 〜ね で 終わる）、同じ ものを 言いかえ つづける
3. **考えの 層**: だれでも 言える 一般論、事情の ぜんぶ 説明、「起・承・結」が きれいすぎて 1ページ けしても 話が 通じる、さいごに 教訓を 言う

書きかえ（casual の 方針）:

- **その 人に しか 言えない 具体を 1つ 入れる。** 場所・物・前の 場面の できごと（「てんき けんきゅうじょの つぎは ここ？」）。口語の 飾り（めっちゃ・ぶっちゃけ）を 足すのは 体温では ない
- **立場を はっきり。** 心配なら 心配と 言う。どっちつかずに しない
- **リズムを くずす。** 長い 行の あとに 短い 一言。全部 同じ 長さに しない
- **言い切れない 気持ちは 言い切らない。** 「…」や 言いさしで 止める（「このままじゃ フリーザーが」）
- **説明は 行動に かえる。** 「〜だから 〜して」より、相手に させたい ことを 一言で

## ② 4つの 視点で 読みくらべる（novel2agent-jp の MoA を 台詞むけに）

一つの 視点ずつ、別の 回で 読む（前の 視点に 引きずられない ため）。サブエージェントに たのむ ときは 視点ごとに 分け、characters/*.toml・facts.toml・場面メモを わたす。
「はい／いいえ＋根拠（どの 行か）」で 答える。根拠の ない 答えは 数えない。

| # | 視点 | 問い |
|---|---|---|
| 1 | **キャラの 口調** | 一人称・主人公の 呼び方・語尾・口ぐせは characters/*.toml（[official] が 先）と 合って いるか。名札を かくしても だれの 台詞か わかるか。2人が 同じ 口調に なって いないか |
| 2 | **話の つながり** | 前後の イベントと 矛盾しないか（facts.toml）。その 時点で 知らない ことを 言って いないか（知識状態）。指示語（あの こ・それ）の 指す ものは 画面に あるか |
| 3 | **説明くささ** | 仕組みや 事情を 台詞で 説明して いないか。プレイヤーが 画面で 見て いる ことを くりかえして いないか。けしても 話が 通じる 行は ないか |
| 4 | **テンポ** | 1回の 話しかけが 3ページを こえて いないか。1ページ 1〜2行か。間（…）が 多すぎないか。場面の 山（オーラが きえる 等）の まえで 台詞が 長く なって いないか |

## ③ 禁止語・言いすぎの 言葉

一覧は banned_words.toml（道具が 読む）。一つ 出た だけで だめでは ない。まとまって 出たら 書きなおす。
とくに この プロジェクトで 嫌われた もの（メモ dialogue-skills）:

- 仕組みの 説明（「マスターボールと おなじ ちから」）
- 事情を ぜんぶ しゃべる
- 全員 同じ 口調
- 説明くさい つなぎ（つまり・と いう ことは・なぜなら）

## 直さない もの

- 悪役が 主人公を「こども」「ガキ」と よぶ（わざと）
- ポケモンを「こ」と よぶ（「もってる こよ」＝ 子よ。誤字では ない）。ひらがなの 台詞は 意味を 読んでから 誤字と きめる
- 台本の 注に「仮の 台詞」と ある 所を、たのまれて いないのに 書きかえない
