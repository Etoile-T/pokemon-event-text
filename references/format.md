# 台本の 書き方の 決まり

**手本は 元の 日本語版 ファイアレッド（BPRJ）の 台詞。** 数字は 2026-11-15 に ROM から 取り出した
公式の 台詞（`scripts/extract_official_text.py` の 控え、ヘルプ・看板を のぞく 台詞 3503件・11016行）を
`scripts/find_official.py --style` で 数えた もの。改造で 決めた ことは【改造】と 書く。
英語の 台本（vendor/pokefirered・data/maps/*_Frlg の 英文）は ビルドで 日本語に 置きかわる 元なので、手本に しない。

## 字と 空白

- **かな と カタカナ だけ。漢字は 使わない。**（公式の 台詞の 漢字は「円」11字だけ）
- **文節ごとに 空白を 1つ。**
  - ROM の 空白は 1種類だけ（字 00。1字分の 幅）。台本で 半角「 」と 書いても 全角「　」と 書いても 同じ 字に なる（charmap.txt）
  - 公式の 文は ビルドで 全角「　」の 形で 出て くる（build/generated/bprj_text）。【改造】新しく 書く 台詞は 半角で よい（いまの 台本の 書き方。見た目は 同じ）。1つの ラベルの 中で まぜない
  - 空白の 入れ方は 公式に あわせる: 助詞の あと（ポケモンを　さがした）、「！」「？」が 行の とちゅうに 来たら その あとにも 空白（よう　{PLAYER}！　…。公式 243回 / つめて 書く 25回）
- 句読点「、」「。」は 台詞で 使わない（公式の 台詞で 「、」0回・「。」12回。「。」は ヘルプの 文だけ）
- 「〜」「（ ）」「―」は 公式に ない（charmap にも ない）。かっこは「」で、物や わざの 名前を 引く ときだけ（わざマシン「…」）
- 数は 半角の 数字（3びき、わざマシン19）

## 記号

| 記号 | 公式の 使い方（数） | 書く とき |
|---|---|---|
| ！ | ページの 終わりの 48% が ！。！！ は 6回・！？ は 8回だけ | ふつうの 文末。重ねない |
| ？ | ページの 終わりの 10% | 問いかけ |
| … | 1つの「…」が 1210回、「……」221回、3つ 以上 26回。「…」の あとは 空白が ふつう（494回 / 字が つづく 109回）。行の 頭の「…　」も 多い（257回） | **ふだんは「…」1つ。** 長い 間・だまる ときだけ「……」か「…　…」「……　……」 |
| 記号なし | ページの 終わりの 35% | 言い切りで 止めて よい |
| ー | ひらがなの 中の のばし（ねーよ・よーし・うーん）683回 | 口語の のばしに 使う |
| ッ | さけびの 小さい つ は カタカナ（あッ！・くッ・はーはッ）。「ッ！」148回 /「っ！」40回 | さけび・おどろきは「ッ」が 公式の 型。【改造】の 台詞の「っ」は まちがいでは ない |
| 「」 | 物・わざ・名前を 引く とき（14回） | 鳴き声には 使わない |
| 』 | 題名を はさむ とき だけ（『またまた　タマタマ』） | 名札の 閉じには 書かない |

## 1行の 長さ

公式の 台詞の 行（{PLAYER} {RIVAL} は 5字、{KUN} は 2字で 数える）:

| 字数 | 14字まで | 15 | 16 | 17 | 18 | 19 | 21 |
|---|---|---|---|---|---|---|---|
| その 長さまでの 行 | 74% | 84% | 92% | **97.9%** | **99.3%** | 99.5% | 99.9% |

- 平均は 1行 11〜12字。**目安は 17字まで、18字を こえたら 書きなおす。**（2026-11-15 に 21字から 公式に あわせた）
- 窓には 27字まで 入る（幅 27 タイル × 8px。src/menu.c の sStandardTextBox_WindowTemplates、src/text.c の GetJapaneseGlyphWidth）。それを こえると はみ出す
- 【改造】電話（pokenavcall）は 公式の FR に ない。窓は 24字（幅 28 タイル、顔の 絵の 分 32px あける。src/match_call.c）。目安は ふつうの 窓と 同じ 18字まで
- 置きかえ文字: 公式の 名前は 5字だが、この 改造の {PLAYER} {RIVAL} は 7字まで（PLAYER_NAME_LENGTH 7）、{KUN} は「くん」2字か「ちゃん」3字。いちばん 長い ときに 27字（電話 24字）を こえないか 道具が 見る
- 名札「名前『」の 部分は 名前の 窓に うつるので、1行目の 長さに 入れない

## 改行と ページ

公式の 1ページの 行の 数: 1行 21% / **2行 52%** / 3行 21% / 4行 4%。1つの 台詞（ラベル）は 1ページが 71%、2ページ 18%。

- 窓は 2行。`\n` は 1行目 → 2行目
- 3行目から 先は `\l`（上に 送る）か `\p`（窓を 消して 次の ページ）。**1ページに `\n` を 2つ 書かない**
- `\p` は 話の まとまりの 切れ目。同じ 話を もう 1行 つづける ときは `\l` で 3行目を 足して よい（公式の ページの 2割は 3行）。4行 いじょうは まれ
- 文の 終わりは かならず `$`
- 1つの ラベルは `.string "…\n"` `.string "…\p"` `.string "…$"` と 1行ずつ 書く

```
Route9_Text_NanamiBye::
	.string "ナナミ『にげた ふたりを\n"
	.string "おいかけて みる\p"
	.string "{PLAYER}{KUN}も むりは しないでね$"
```

## 名札

公式の FR にも ページの 頭の「名前『」が ある（{RIVAL}『・オーキド『・ナナミ『・マサキ『 など。台詞 3503件の うち 292件）。
閉じの 』は 書かない。公式で 名札が つくのは 名前の ある 人が 話す 場面の 台詞で、町の 人・トレーナーの 台詞には つかない。
【改造】名札の 窓の 仕組みは src/field_speaker_prefix.c（ConvertSpeakerPrefixesToNamebox）。

- 書き方は **`名前『`**。名前は 名前の 窓に うつり、本文から 消える
- **閉じの `』` は 書かない。** 名札と 同じ 行に `』` が あると 題名と みなされ、名札に ならない（IsClosedOnSameLine）
- 名札が きくのは **ページの 頭だけ**（文の 頭 と `\p` の あと）。`\n` や `\l` の あとに 書いても 名札に ならない
- 名前は 8字まで、空白なし（SPEAKER_NAME_MAX_GLYPHS）。`{RIVAL}『` は 使える
- 話し手が かわる ページには かならず 新しい 名札。書かない ページは 前の 名札の まま
- 【改造】名札を 書かない 台詞（町の 人・勝負の まえの トレーナー）は、見た目から 名札が 自動で 出る（名前の ある 人 → トレーナーの 種類 → 役目 → 呼び名。src/data/speaker_npc_labels.h）。看板は「かんばん」、黒い 字の 地の文は「システム」
- 【改造】名前の ある 人（sKnownSpeakers）が まだ 画面に いない ときは、名札が 自動で「？？？」に なる。電話では 名前の まま。姿を 見せる まえの 声は `？？？『{PLAYER}{KUN}！$` と 書いて よい（公式には ない 書き方）
- 名札を 出さない 人（シルバーなど）は スクリプトで `setspeaker ラベル`
- 話し手の 色は `textcolor NPC_TEXT_COLOR_FEMALE / MALE / NEUTRAL`（地の文は NEUTRAL）

## ポケモンの 鳴き声

- 公式は `ピッピ『ぴ　ぴっぴ！` `ニョロボン『ゲロゲーロ！` の 形（名札＋鳴き声、「」なし）
- **「」で 囲まない。**（メモ mon-lines-no-brackets）
- 町に いる ポケモンは 名札を 書かずに `ブイブイッ！$` で よい（見た目から 名札が 出る）
- 鳴き声の まえに スクリプトで `playmoncry SPECIES_…` `waitmoncry`

## 地の文（システムの 文）

公式の 地の文（{PLAYER}は 〜を ○○！）の 動詞の 数:

| 言い方 | 数 | 公式で 使う 場面 |
|---|---|---|
| **もらった！** | 47 | 人から わたされた もの すべて。ポケモンも（オーキドの あいぼう・カラテだいおうの ポケモン・しゃいんの ラプラス・タマゴ）、どうぐ・わざマシン・コイン |
| わたした！ | 5 | 主人公が 人に わたす（おとどけもの・ルビー） |
| みつけた！ | 4 | 落ちて いる どうぐ・ルビー・サファイア |
| うけとった！ | 2 | はかせから 生きかえった ポケモン、ランニングシューズ |
| てにいれた！ | 2 | 人が わたさない とき（テーブルの ボールの イーブイ、景品の ポケモン）。**つめて「てにいれた」と 書く** |
| あずけた！ | 1 | 化石を はかせに |
| なかまに なった！ | 0 | 公式には ない |

- 型: `{PLAYER}は　○○から\n△△を　もらった！$`（「から」で 改行して、もらう 物を 2行目に）。○○は「エリカ　から」「おじさんから」の ように 人の 名前か 呼び名
- 公式の 地の文の ページの 終わりは 8割が「！」
- **主人公の 名前は `{PLAYER}` だけ。`{KUN}` は 付けない**（公式の 地の文も {PLAYER}だけ）
- 【改造】ポケモンが 自分から ついて くる ときの `{PLAYER}の なかまに なった！`（9ばんの フリーザー）は 2026-11-15 に ユーザーが きめた 改造の 言い方。公式の 型では「てにいれた！」に あたる
- 人から わたされた ポケモンは 公式どおり「もらった！」（「うけとった！」は 公式では 2回だけ）
- 見た ことを 1〜2行で。気持ちを 書かない。ようすの 文は「…」で 終えて よい

## 電話（pokenavcall）【改造】

公式の FR には 電話が ない。

- スクリプト: `pokenavcall ラベル` → `waitmessage` → `closemessage`。家の 中では 電話が できない
- 文は 名札つき: `ナナミ『もしもし {PLAYER}{KUN}？\n…`。名札なしで 名のる 形も ある（nanami_dates.inc）
- 1行 18字まで が 目安（上を 見る）。3ページ 前後
- エントリーコールの 定まった 電話は data/text/match_call.inc の MatchCall_Text_*

## 台詞の 中身

- 短く。公式の 1ページは 2行が ふつう、町の 人・トレーナーは 1件 1〜2ページ。名前の ある 人の 大事な 場面だけ 長く なる（グリーンの 勝負の あと など）
- 説明しない。仕組みや 事情の ぜんぶを しゃべらせない。わかって いる ことの 一部だけ、行動と いっしょに
- 人物ごとの 声で（characters/*.toml。[official] が 公式の 数、[project] が 改造で 足した こと）
- 公式の 台詞を そのまま 写さない。型（語尾・呼び方・行の 長さ・記号）を あわせる。BW・HGSS の 台詞も 公開リポジトリに 入れない
- 悪役の「こども」「ガキ」は わざと。直さない（公式の したっぱも「こども」7回・「ガキ」2回）
- 恋人の 場面は におわせる 程度

## 特性・道具の 説明（src/data/abilities.h・items.h）【改造】

- 公式の 特性の 説明は ほぼ 1行（このROMの 326件中 323件）。1行は 14〜20字が 多く、長くても 21字
- 効果が いくつも ある 特性でも、書くのは いちばん 目立つ 1つ（ハドロンエンジン →「エレキフィールドを はりめぐらせる」、しんがん →「ゴーストタイプに わざが あたる」）
- 動きの ある 短い 文に する（「みず でんき ほのおを すいとる」「ひこうわざを さきに だせる」）。名詞を ならべない（✕「エレキフィールド はんどうなし」「でんきわざ せんせい はんどうなし」→ 箇条書きに 見える）
- 改造の 専用特性で どうしても 足りない ときだけ 2行（きずならいげき「でんきわざを さきに だせる／とくせいも タイプも むしして あたる」、2026-11-17 ユーザーが えらんだ）。1行 19字まで
- 書いたら つよさの 画面（2ページ目）で 撮って、枠から はみ出さないか 確かめる。勝負の 中だけの 姿は、勝負の 中で 手持ち → つよさを みる で 開く
